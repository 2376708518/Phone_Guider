# 📖 参数形象化解释指南

## 🎯 为什么需要参数解释？

### 问题
RAG 库里的参数虽然详细，但普通用户**对这些数字没概念**：

```
❌ 用户看不懂的参数堆砌：
- 处理器：骁龙 8 Elite
- 电池：6000mAh
- 充电：120W
- 屏幕：2K AMOLED
```

### 解决方案
**把参数翻译成生活场景**：

```
✅ 用户能懂的形象解释：
🚀 处理器：骁龙 8 Elite【顶级】
   原神最高画质稳定 60 帧，玩 3 小时只微热

🔋 电池：6000mAh【超大电池】
   重度使用一天半，刷抖音能看 15 小时

⚡ 充电：120W【超快充电】
   15-20 分钟充满，洗脸刷牙的功夫就满了

📱 屏幕：2K AMOLED【超高清】
   看文字非常清晰，像印刷品一样
```

## 🎯 回答技巧

### 1. 先说结论，再解释参数
```
✅ "这款性能很强，用的是骁龙 8 Elite（顶级芯片）"
❌ "这款用的是骁龙 8 Elite，所以性能很强"
```

### 2. 用生活场景代替数字
```
✅ "刷抖音能看 12 小时"
❌ "电池 6000mAh"
```

### 3. 给出对比参照
```
✅ "比 iPhone 16 Pro Max 还大"
❌ "6.9 英寸"
```

### 4. 说明适用人群
```
✅ "适合重度游戏玩家"
❌ "性能很强"
```

### 5. 给出购买建议
```
✅ "这个价位最推荐，性能够用 3 年"
❌ "性价比很高"
```
